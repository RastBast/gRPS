# MISTAKES

Журнал повторяющихся ошибок. Ошибка попадает сюда один раз; повторилась — счётчик растёт.
Перед каждым коммитом пробегай список глазами.

## 1. Сгенерированный код попал в git, причём в двух папках (2026-09-14)

- Что: `order.pb.go` и `order_grpc.pb.go` закоммичены И в корневой `orders/v1/`, И в `proto/orders/v1/`.
  Хуже: исходник `proto/orders/v1/order.proto` в git вообще не попал — в репе лежит код,
  сгенерированный из файла, которого в репе нет.
- Почему: (а) `.gitignore` не прикрывал `*.pb.go`; (б) конфиг генерации менялся,
  а старые артефакты не вычищались; (в) коммит сделан вслепую, без чтения `git status`.
- Правило: `.gitignore` настраивается ДО первой генерации. Перед коммитом — читать `git status`.
  В git не должно быть ничего, чего ты не можешь объяснить: «оно само добавилось» — не ответ.

## 2. «Запушил» без проверки (2026-09-14)

- Что: заявил «запушил, можешь посмотреть» — на GitHub остался старый коммит e5eb498.
- Правило: пуш существует только если `git ls-remote origin master` показывает твой хэш
  (`git rev-parse HEAD`). Совпало — долетело. Не совпало — работы нет.
